# HarmonyOS 代码生成检查

在生成代码前，先按 `SKILL.md` 的资料入口选择领域目录，再通过标题路由定位并读取对应原始 Markdown。

## 最小检查

- 是否从资料入口选择了相机开发、图片处理或 ArkUI 开发。
- 是否进入了对应领域的最佳实践或 FAQ 路由文件。
- 二级路由是否只使用标题关键词。
- 是否已经读取命中的 `sources/` 原文。
- 如果没有命中标题，是否明确说明本地标题路由未覆盖。

## 输出要求

- 不凭路由文件直接生成最终代码。
- 引用接口或流程时，以读取过的原始 Markdown 为依据。
- 不把路由标题扩展成自定义关键词库。
