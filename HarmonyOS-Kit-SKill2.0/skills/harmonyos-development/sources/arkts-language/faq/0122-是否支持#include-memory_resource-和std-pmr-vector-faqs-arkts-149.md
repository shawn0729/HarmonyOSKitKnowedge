# 是否支持#include <memory_resource>和std::pmr::vector

暂时不支持。



C++从C++17标准开始正式支持 <memory_resource> 和std::pmr::vector等“多态内存资源”容器，开发者可以直接在sdk下查询到当前llvm版本是15.0.4，暂时不支持部分C++17高级特性。
