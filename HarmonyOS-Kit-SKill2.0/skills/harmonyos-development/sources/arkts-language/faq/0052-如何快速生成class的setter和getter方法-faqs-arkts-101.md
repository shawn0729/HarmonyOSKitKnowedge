# 如何快速生成class的setter和getter方法

1. 在类内部，右键点击，选择“生成”。     ![](../../_assets/images/2959786591a54e8ffaf3b0c2.webp "点击放大")

2. 选择Getter and Setter。     ![](../../_assets/images/f1450c35b448c4e6961d3c80.webp "点击放大")

3. 选择要生成Getters和Setters的字段，点击OK，快速生成。     ![](../../_assets/images/f262225d2752147f6506cbc8.webp "点击放大")
