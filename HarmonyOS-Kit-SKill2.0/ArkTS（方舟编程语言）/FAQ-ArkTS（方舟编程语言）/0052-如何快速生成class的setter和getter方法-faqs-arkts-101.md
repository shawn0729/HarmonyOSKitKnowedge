# 如何快速生成class的setter和getter方法

1. 在类内部，右键点击，选择“生成”。     ![](../assets/0052-如何快速生成class的setter和getter方法-faqs-arkts-101-image-001.png "点击放大")

2. 选择Getter and Setter。     ![](../assets/0052-如何快速生成class的setter和getter方法-faqs-arkts-101-image-002.png "点击放大")

3. 选择要生成Getters和Setters的字段，点击OK，快速生成。     ![](../assets/0052-如何快速生成class的setter和getter方法-faqs-arkts-101-image-003.png "点击放大")
