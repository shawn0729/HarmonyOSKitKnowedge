# Kit 任务场景覆盖

## network-kit-development

- 网络请求迁移。
- 长连接和双向通信迁移。
- 网络状态监听和网络可用性判断。
- 弱网、取消、超时和并发限制排障。
- 局域网发现、专用网络和安全连接能力识别。

## arkdata-development

- 本地键值持久化迁移。
- 关系型数据存储迁移。
- 标准化数据、跨设备数据和跨应用数据共享识别。

## arkts-development

- JSON、XML、二进制数据和容器类相关的数据处理迁移。

详细用法、模块引用和具体异常处理读取对应 Kit 的 `routing.md`，不要把细节清单放在触发层。
