## Routing Rules
- 基础语法与组件定义：优先读取 `references/component-composition.md`，必要时回到 `sources/ArkUI.md` 对应章节
- 状态管理：优先读取 `references/state-management.md`，必要时回到 `sources/ArkUI.md` 对应章节
- 渲染控制与列表：优先读取 `references/rendering-navigation.md`，必要时回到 `sources/ArkUI.md` 对应章节
- 导航与页面路由：优先读取 `references/rendering-navigation.md`，必要时回到 `sources/ArkUI.md` 对应章节
- 样式、布局、动画与主题：优先读取 `references/styling-animation.md`，必要时回到 `sources/ArkUI.md` 对应章节
- FAQ 与故障排查：优先读取 `references/best-practices-and-faq.md`，必要时回到 `sources/ArkUI.md` 对应章节
- 主题不明确时，先读取 `references/overview-and-routing.md`，再回到 `sources/ArkUI.md` 的总览或路由章节
- API 条目定位时，优先读取 `references/api-map.md`，再回到 `sources/ArkUI.md` 中的 API 章节
- `references/*.md` 是当前阶段的首选路由索引，但 `sources/ArkUI.md` 仍是最终依据
